# Care-Connect
A Website designed to facilitate in-home support service which provides special personalised support to individuals who cannot take care of daily life activities like senior citizens,kids and physically or mentally  challenged people .

# Features
1. Get in-home support from professionally trained individuals.

2. Get 24/7 services.

3. Flexible Plans  ranging from daily to yearly.

4. Affordable services.

5. Safe and Security with incidence reporting functionality and location tracking.
